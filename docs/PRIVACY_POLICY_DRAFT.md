# Frames Privacy Policy Draft

Last updated: August 17, 2026

Frames helps users capture, share, and preserve personal memories.

## Data We Collect

- Account information such as username, display name, email, avatar, and password hash.
- User content such as photos, videos, captions, comments, reactions, scrapbook cards, collages, and yearbooks.
- Optional location information when the user chooses to add a place.
- Friendship and block relationships.
- Notification records.
- Technical information such as API logs, errors, and basic analytics events.

## How Data Is Used

- To authenticate users.
- To show 24-hour social feeds.
- To preserve private archive memories.
- To generate daily, monthly, and yearly scrapbook views.
- To send notifications.
- To enforce privacy, friendship, and block settings.
- To improve reliability and security.

## Sharing

Posts may be shared as Public or Friends-only based on user selection. Archive content remains private unless the user explicitly creates a share link.

## Location

Location is optional. Users can post without location and can remove location before posting.

## Media

Original media is stored separately from the database. Generated scrapbook renderings do not destroy original media.
